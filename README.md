# Last Bite — демо-шаблон сайту (concept)

Статичний сайт без збірки: відкрийте `index.html` або викладіть папку на GitHub Pages / Cloudflare Pages.
Рекомендація: репозиторій **приватний** (на сторінках реальна назва бізнесу), у `robots.txt` і `noindex` індексація вимкнена.

## Сторінки
- `index.html` — головна (hero, популярні страви, конструктор, відгуки, години, карта, FAQ)
- `menu/index.html` — меню з пошуком, фільтрами та працюючим кошиком (доставка/самовивіз, промокод WELCOME10, демо-checkout)
- `build-burger/index.html` — конструктор бургера з живою ціною та алергенами

## Що реальне, що ілюстративне
- Реальне: назва, адреса, телефон, години (12:00–22:00 щодня), рейтинг 4.9 / 365, три відгуки, Instagram.
- Ілюстративне: меню, ціни, збори, мінімальне замовлення, промокод. Усе, що позначено жовтим `[...]`, — заглушки, які має підтвердити власник.
- Кошик зберігається в localStorage браузера; замовлення нікуди не надсилається.

## Генератор
Дивіться `generator-burger/`: `python3 build.py clients/lastbite.json ../lastbite-site`. Усі дані клієнта лежать у JSON.
